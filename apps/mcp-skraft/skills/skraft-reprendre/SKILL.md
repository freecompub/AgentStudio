---
name: skraft-reprendre
description: "Reprend les runs skraft interrompus sur le projet, si aucun autre serveur ne le pilote. Usage : /skraft-reprendre."
---

Appelle l'outil MCP `skraft_reprendre` du serveur `skraft`, sans argument.

Dis ce que la réponse indique : runs repris, ou serveur en consultation parce qu'un autre le pilote
(et lequel). Pour suivre un run repris : `/skraft-attendre`.

Les questions de skraft, et celles que le client affiche (ouvrir un dépôt, autoriser un programme, écrire un profil), reviennent à l'utilisateur : tu ne réponds jamais à la place de l'utilisateur.
